# Evidence Status

所有研究与评估结果都应带上证据状态，避免把猜测直接推进到实施阶段。

## 分类

### 已官方验证
适用于已经被官方来源直接支持的事实，例如：
- 官方网站
- 官方定价页
- 官方应用商店页面
- 官方文档
- 官方 marketplace listing

### 部分验证
适用于已有多个来源支持，但仍缺少完整官方闭环的判断，例如：
- 多个评论源和产品页能互相印证
- 市场方向明确，但关键商业约束仍待确认

### 未完全验证
适用于仍然会影响是否进入实施规划的关键不确定项，例如：
- 定价不清楚
- 平台覆盖不清楚
- 关键功能边界不清楚
- 法律或生态依赖风险不清楚
- 用户付费意愿仍主要来自推测

## 使用规则
- 每个 Top candidate 至少要给出一个总的 evidence status
- 如果未完全验证项会影响 build / no-build 判断，必须显式写出来
- 不要把 evidence status 藏在附件里，摘要里也要出现
