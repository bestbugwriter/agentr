# Getting Started

## 1. Read the repo contract
Start with:
- `instruction.md`
- `memory/memory-spec.md`
- `docs/WORKING-CONVENTIONS.md`

## 2. Choose the current stage
- `commands/rewrite-research.md`
- `commands/rewrite-evaluate.md`
- `commands/rewrite-plan.md`
- `commands/rewrite-package-codex.md`
- `commands/rewrite-package-claude-code.md`

## 3. Produce artifacts in order
Follow the templates and keep outputs staged by workflow phase.
Do not skip directly to implementation planning when evidence is still weak.
Use:
- `docs/output-order.md`
- `docs/evidence-status.md`

## 4. Store reusable findings
Only save durable patterns, validated conclusions, and reusable source strategies.
Do not save one-off scratch notes as memory.

## 5. Commit by stage
Recommended commit rhythm:
- repo scaffold
- research pass
- shortlist / evaluation pass
- planning pass
- delivery packaging pass

## 6. Before sharing or merging
Run the checks in `docs/RELEASE-CHECKLIST.md`.
