# Memory Spec

当前智能体使用 Memory 的原则如下：

## 作用
Memory 用于保存高复用研究结论，而不是一次性草稿。

## 优先维护的文件
- `opportunity-watchlist.md`：值得持续关注的软件赛道和候选机会
- `evaluation-history.md`：已经评估过的软件、结论和主要否定原因
- `pattern-library.md`：反复验证有效的判断模式，例如“高溢价 + 低护城河 + 平台空白”
- `source-playbook.md`：不同平台和研究目标下，已验证有效的来源组合

## 何时写入
只有当结论足够明确、未来可能复用时，才写入 Memory。

## 不应写入
- 一次性草稿
- 低置信度猜测
- 还没有形成稳定结论的研究片段
