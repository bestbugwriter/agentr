# 软件机会评估

核心能力：
- 赛道扫描
- 单软件深度评估
- 多软件对比
- 机会清单输出

关键特性：
- 先做平台与来源路由
- 维护 source log
- 输出 opportunity candidates
- 输出 opportunity scorecard
- 输出 initial assessment report
- 主动识别 iOS / Android / Web 等补位机会
- 产出可衔接实施规划的建议

当前版本的评估要求包括：
- 定价、套餐、功能范围、平台覆盖等硬结论必须回到官方来源验证
- 多平台产品要分平台记录证据
- 对未完全验证项必须显式标注
- 多候选比较时必须给出 candidates 表和 scorecard
- 扫描类请求需要能产出 source log、assessment report 和 Top 3 衔接建议

注：完整工作流细则当前保存在已附加技能本体中；这个导出文件用于本地理解与迁移。
