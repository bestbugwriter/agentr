# 平台感知研究路由

核心能力：
- 按平台选择研究来源
- 区分 discovery sources、secondary sources、official validation sources
- 处理 iOS / Android / web_saas / windows / macos / linux
- 处理生态型产品（如 Shopify / Slack / 浏览器扩展）

当前规则：
- 候选发现可用榜单与目录站
- 功能与定价验证必须回到官网、官方文档、官方商店或官方 marketplace
- 多平台产品要按平台分别记录证据
- 来源冲突时，默认官方来源优先
