# Source Routing Cheatsheet

## 平台优先级

### iOS / Android
1. 应用商店 listing / ranking
2. 官方网站 / 定价页
3. 评论与评分
4. 第三方榜单与评测

### Web SaaS
1. 官方网站 / pricing / docs / demo
2. G2 / Capterra / Product Hunt / 专业目录用于发现
3. 用户社区与讨论区用于补充情绪和痛点

### Desktop
1. 官方网站 / 下载页 / 定价
2. 官方商店或分发平台
3. AlternativeTo / 对比目录
4. 社区与论坛

## 常见警告
- 评论站适合看情绪，不适合单独决定功能范围
- 官方 pricing 缺失时要标记“价格不透明”
- 平台补位判断要确认不是“只是没有被你搜到”
