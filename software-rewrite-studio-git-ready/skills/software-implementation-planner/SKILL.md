# 软件实施规划

核心能力：
- 把高潜力机会转成 MVP
- 输出技术方案与架构
- 生成开发任务清单

当前规则：
- 先确认产品、目标用户、核心价值、付费逻辑与主要风险
- MVP 必须区分：必做 / 可选增强 / 明确不做
- 技术方案优先服务“快速验证机会”，不要过度设计
- 任务拆解必须细到可直接给 AI coding agent 使用
