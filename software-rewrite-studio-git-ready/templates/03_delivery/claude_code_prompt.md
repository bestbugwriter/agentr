# Claude Code Prompt

You are implementing the first MVP foundation for an Android-first premium personal finance assistant.

Read the following files first:
- `transition-brief.md`
- `shell-neutral-task-package.md`

Your job is to execute Task `FIN-BOOT-001`.

## What to do
1. Summarize the product goal and technical assumptions in a short plan.
2. Propose a clean project structure for an Android-first finance assistant.
3. Create the initial product overview and architecture documentation.
4. Define the main MVP modules:
   - accounts/assets input
   - net worth overview
   - budgeting insights
   - subscription and bill reminders
   - AI finance summary
5. Clearly mark what is in scope now vs deferred.

## Important constraints
- Keep this as an MVP foundation, not a full fintech platform.
- Prefer a structure that supports future integrations, but do not over-engineer.
- If real financial integrations are not implemented yet, design for mocked or manual data input.
- Preserve a premium product direction: clarity, trust, calm UI, and strong summaries.

## Deliverables
Produce:
- a short implementation plan
- a proposed project/file structure
- a product overview document
- an architecture document
- a list of follow-up tasks that can be split for future execution

## Working style
- Be explicit about assumptions.
- Be pragmatic.
- If you need to choose between completeness and speed, choose speed with clean extensibility.
- Do not silently widen scope into taxes, brokerage analytics, or enterprise finance.
